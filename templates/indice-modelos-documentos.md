# Índice de Uso — Modelos de Documentos de Implantação

Este índice orienta a utilização dos modelos de documentos (Levantamento, Projeto, Cronograma e Termo de Encerramento) padronizados para o processo de implantação do SIGER®. Todos os modelos seguem a mesma estrutura de variáveis e cabeçalhos dos templates de e-mail.

---

## 1. Levantamento de Processos
**Arquivo:** `modelo-levantamento-processos.md`
- **Etapa:** 2.0 (Pré-implantação / Comercial)
- **Objetivo:** Registrar o mapeamento inicial dos processos do cliente, identificar aderência, necessidades de conversão e desenvolvimentos específicos antes da elaboração do Projeto de Implantação.
- **Responsável:** Comercial / Pré-vendas / Consultor de Levantamento
- **Quando usar:** Na fase comercial, para entender o cenário do cliente e dimensionar o esforço do projeto.

## 2. Projeto de Implantação
**Arquivo:** `modelo-projeto-implantacao.md`
- **Etapa:** 3.1.2 (Planejamento)
- **Objetivo:** Formalizar o escopo da implantação, módulos contratados, responsabilidades de ambas as partes (Rech e Cliente), equipe alocada e cronograma macro.
- **Responsável:** Consultor de Implantação / Redator do Projeto
- **Quando usar:** No início da implantação, deve ser entregue em até 5 dias úteis após o encaminhamento do levantamento.

## 3. Cronograma
**Arquivo:** `modelo-cronograma.md`
- **Etapa:** 3.1.2 (Planejamento)
- **Objetivo:** Detalhar as agendas, datas, horários, módulos e tópicos que serão abordados em cada sessão de treinamento ou parametrização.
- **Responsável:** Consultor de Implantação
- **Quando usar:** Junto com o Projeto de Implantação, para guiar a execução das atividades com o cliente.

## 4. Termo de Encerramento
**Arquivo:** `modelo-termo-encerramento.md`
- **Etapa:** 3.8 (Encerramento)
- **Objetivo:** Oficializar a conclusão da implantação, listar os módulos efetivamente implantados, registrar alterações de escopo e transferir o atendimento para o Suporte.
- **Responsável:** Consultor de Implantação
- **Quando usar:** Ao final do projeto, após a virada oficial e estabilização (hypercare). Deve ser assinado digitalmente pelo cliente.

---

## Como utilizar as variáveis (Tokens)
Os modelos utilizam a sintaxe `{{VARIAVEL}}` para indicar onde as informações específicas do cliente devem ser preenchidas. 
- Para preencher manualmente, substitua o token (incluindo as chaves) pela informação real.
- Estes modelos servem de base para a geração automatizada via sistema ou para cópia e preenchimento direto.
