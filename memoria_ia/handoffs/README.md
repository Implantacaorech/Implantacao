# handoffs/

Handoffs de sessão (tarefas longas/incompletas). Um arquivo por handoff:

```
AAAA-MM-DD-objetivo.md
```

Use o modelo em [`../../docs/template-handoff-sessao.md`](../../docs/template-handoff-sessao.md).
Mantenha curto: objetivo, estado, arquivos alterados, decisões, pendências, próximos passos, riscos.
