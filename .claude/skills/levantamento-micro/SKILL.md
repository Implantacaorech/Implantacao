# Levantamento de Processos — Micro (detalhado)

**Etapa do processo:** 3.2 · **Responsável:** Consultor
Não é facultativo; o aprofundamento varia com o **porte** do cliente. Ocorre concomitante à
`aderencia-siger`.

## Regra de entrada
- **Houve** mapeamento detalhado na pré-implantação → apenas **refine**.
- **Não houve** → faça o detalhado agora, com o cliente já efetivo, antes do projeto.

## Objetivos
- Identificar o que o cliente realmente busca com a troca de sistema.
- Avaliar customizações possíveis.
- Dimensionar **horas reais** (configuração + treinamento + acompanhamento), considerando:
  perfil dos usuários, complexidade das rotinas, quantos fechamentos mensais exigirão
  acompanhamento.
- Validar **módulos e adicionais** necessários (o que o cliente já tem).
- Identificar pontos do processo atual que o cliente **não abre mão**.
- **Catalogar formulários e relatórios** que exijam aplicação similar no SIGER®.

## Saída
Documento de levantamento **refinado** (template padrão) que alimenta o `projeto-implantacao` e
a `aderencia-siger`.

## Próximo passo
`aderencia-siger` (em paralelo) → `projeto-implantacao`.
