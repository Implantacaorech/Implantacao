# Manutenção da RNS de Implantação

**Etapa do processo:** 3.1.2 · **Responsável:** Consultores + Gerente do Projeto + Coordenação

## Campos e responsáveis

| Campo | Responsável | Regra |
|-------|-------------|-------|
| Status geral da implantação | Consultores | Usar a **predominância** dos módulos |
| Data previsão uso oficial | Gerente do Projeto | Em início parcial, usar a **última** data; registrar motivo ao alterar |
| Data encerramento | Gerente do Projeto | Conclusão definitiva dos trabalhos |
| Status por módulo (aba "Etapas") | Consultores | Atualizar individualmente cada módulo previsto |
| Data transição manutenção | Coordenação / GCI | Informada quando encaminhada a transição |

## Por que o status por módulo importa
A identificação do **status por módulo na etapa de produção** é o que habilita a **liberação do
atendimento simultâneo pelo Suporte**. Mantê-lo correto é crítico.

## Painel de acompanhamento (SICLA)
Crie filtros/painel indicador para acompanhar as RNS de Implantação (roteiro corporativo em
`docs/recursos-e-caminhos.md` → "Criar painel de RNS de Implantação").

## Saída
RNS(I) com campos atualizados e painel configurado. Reflita as mudanças também no
`encerramento-implantacao` (etapa final).
