# Encaminhamento das Conversões

**Etapa do processo:** 3.3.2 · **Responsável:** Setor Adm (abre) + Consultor (refina/redige) +
Equipe de Conversão (executa)

## Fluxo
1. **Setor Adm** abre a RNS com **template padrão**, conforme previsto comercialmente. Nasce
   **pendente**.
2. **Consultor complementa** e indica pontos relevantes antes de **redigir**:
   - **De/para de tabelas:** local de cobrança, grupo de cadastros, representantes etc.
   - **Campos além do padrão:** conta financeira, dados de comissão, dados contábeis etc.
3. **Apontar os tempos na RNS de conversão** (não distorcer o envolvimento).
4. **Passar para "redigida"** → a RNS é validada e vai ao **backlog** da Equipe de Conversão.
5. Indicar na RNS a **previsão de prévia** **e** a **previsão de conversão oficial**.

## Casos especiais
- Se o técnico **tratar os dados sem a equipe de conversão**: aponte os tempos na RNS de
  conversão e **não** passe para redigida.
- Quando o **cliente fornece os dados**: use os layouts em Excel (ver `docs/recursos-e-caminhos.md`).

## Pares ORC → COB comuns
Clientes/Fornecedores · Produtos · Financeiro a Pagar/Receber (em aberto) · Notas Fiscais emitidas.

## Saída
RNS de conversão redigidas, com de/para, campos especiais, tempos e previsões — prontas para a
`equipe-conversao`.
