# Produção (Uso Oficial) e Micro Ajustes

**Etapa do processo:** 3.7 / 3.7.1 · **Responsável:** Consultor

## Objetivos
- Apoiar o uso **full time** do SIGER® como software oficial.
- Promover **ajustes** detectados no uso oficial.
- Acompanhar os **primeiros fechamentos críticos**.
- Condicionar a ambientação para uso **alternado do Suporte**.

## Pontos a observar e refinar
- **Maximizar filtros e seleções salvas** dos usuários (quando perceber oportunidade).
- Ajudar a criar **roteiros para rotinas não diárias** (ex.: encerramento de estoques, apuração
  de impostos).
- **Ajuste de formulários** decorrentes de melhorias percebidas no uso oficial.

## Estratégia de agendas
Concentre acompanhamento **full time nos primeiros dias** e **espace** as agendas após o período
crítico, para reduzir a dependência dos consultores e estimular o uso do Suporte.

## Recursos
Visitas in loco (cronograma), agendas de **plantão** internas (cronograma), Suporte Rech.

## Saída
Cliente estável em produção, com ajustes aplicados → seguir para `encerramento-implantacao`.
