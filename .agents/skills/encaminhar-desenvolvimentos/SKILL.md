# Encaminhamento dos Desenvolvimentos

**Etapa do processo:** 3.3.3 · **Responsável:** Setor Adm (encaminha COB) + Consultor (refina)

## Fluxo
1. Para cada **RNS ORC** de desenvolvimento **aprovada/validada** na etapa comercial, o **Setor
   Adm** encaminha uma **RNS COB**, tendo como **responsável o consultor** que levantou os
   requisitos / o responsável pela implantação.
2. O **consultor refina** pontos relevantes da execução:
   - **Prazo desejável** em função da pretensão de **virada oficial**.
   - **Complementos** de requisito que **não alterem** o formato do orçamento inicial aprovado.

## Atenção
- Mudanças que **alterem o escopo/orçamento** devem voltar ao fluxo comercial (nova ORC), não
  entram como complemento.
- Aponte os tempos na RNS COB de desenvolvimento.

## Saída
RNS COB de desenvolvimento refinada (prazo + complementos) pronta para a equipe de desenvolvimento.
