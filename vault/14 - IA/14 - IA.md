## Busca semântica sobre o Vault (RAG-lite, implementado em 2026-07-19)

`tools/vault_busca_semantica.py` — protótipo real e funcional, não um design especulativo:

- Embeddings via API Gemini (`gemini-embedding-001`, mesma chave já validada em
  [[22 - Troubleshooting]]), cacheados em `tools/data/vault_embeddings.json` (gerado, fora
  do git — só reprocessa notas cujo hash de conteúdo mudou).
- Busca por cosseno em memória — o Vault tem só dezenas de notas, não precisa de banco
  vetorial de verdade.
- **Testado de ponta a ponta:** 27 notas indexadas; a pergunta *"como fazer login e renovar
  o token"* trouxe [[10 - Fluxogramas]] e [[09 - Casos de Uso]] como top resultados
  (score de cosseno 0.67 e 0.64) — exatamente onde esse assunto vive.

```bash
python tools/vault_busca_semantica.py --indexar        # (re)constrói o índice
python tools/vault_busca_semantica.py "sua pergunta"    # busca
```

**Isto é deliberadamente "RAG-lite"**, não o "banco vetorial + Knowledge Graph +
indexação inteligente" completo pedido no prompt original — ver por quê e o que falta em
[[19 - Roadmap]]. Não toca em `backend`/`frontend` de produção; é uma ferramenta de
documentação, no mesmo espírito de `tools/gerar_*`.
