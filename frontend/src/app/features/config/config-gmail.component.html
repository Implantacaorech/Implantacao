Abre o navegador para você entrar na conta implantacao.rechsistemas@gmail.com e permitir o envio. Faça isto na máquina onde o painel roda.

Como criar a credencial (uma vez)

  1. Acesse console.cloud.google.com (logado na conta de implantação) e crie um projeto.
  2. Em APIs e serviços → Biblioteca, habilite a Gmail API.
  3. Em Tela de consentimento OAuth: tipo Externo, modo Teste, adicione o e-mail como usuário de teste.
  4. Na Tela de consentimento, clique em Publicar app (status "Em produção") — senão o acesso expira a cada 7 dias. Aceite o aviso de "app não verificado".
  5. Em Credenciais → Criar credenciais → ID do cliente OAuth: tipo App para computador → baixe o JSON.
  6. Volte aqui: carregue o JSON (passo 1) e clique em Autorizar (passo 2). No navegador, em "app não verificado", clique Avançado → Acessar (não seguro).
