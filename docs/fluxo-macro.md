# Fluxo Macro do Processo de Implantação

O processo compreende **duas grandes etapas**.

## 1. Pré-implantação (apoio comercial)

Atividades de apoio ao Comercial para **levantamento** e **demonstração** em clientes,
ainda na fase de pré-fechamento. Registros no SICLA com **atividade tipo 12**.

```
Comercial solicita à Coordenação
        │
        ▼
Coordenação designa consultor(es)  ──►  Setor Adm elabora documento de levantamento (template padrão)
        │                                         │
        ▼                                         ▼
Consultor executa levantamento / demonstração ◄── link no Google Drive
        │
        ▼
Devolutiva ao Comercial (módulos, RNS de orçamento, viabilidade de conversão, horas)
```

## 2. Implantação (pós-contrato)

O cliente já assinou contrato; iniciam-se as etapas de implantação do SIGER®.
Registros no SICLA com **atividade tipo 13**.

```
Fechamento + contrato
        │
        ▼
Comercial envia RNS de instalação ──► GTI instala o SIGER®
        │
        ▼
Coordenação recebe "liberação para implantação"
        │
        ▼
Setor Adm abre a RNS de Implantação e formaliza e-mail aos consultores
        │
        ▼
┌───────────────────────────────────────────────────────────────────┐
│  Levantamento (micro) → Aderência ao SIGER → Planejamento          │
│  (Projeto + Cronograma) → Execução (Parametrização + Treinamento)  │
│  → Simulações → Virada Oficial → Produção → Encerramento           │
└───────────────────────────────────────────────────────────────────┘
        │
        ▼
Transição para Manutenção/Suporte (Termo de Encerramento + e-mail à Coordenação/Gerência)
```

## Marcos e prazos

- **5 dias úteis** (após liberação do levantamento, com a RNS(I) criada): elaboração do
  **Projeto**, do **Cronograma** e inclusão das agendas no SICLA.
- **Data prevista de uso oficial** e **data de encerramento**: mantidas na RNS(I) pelo
  **Gerente do Projeto**.
- **Status por módulo** (aba "Etapas" da RNS(I)): mantido pelos **Consultores**; é o que
  habilita o atendimento simultâneo pelo Suporte.

Ver detalhamento em [processo-implantacao.md](processo-implantacao.md).
