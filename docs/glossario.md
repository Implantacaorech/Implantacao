# Glossário

Termos e siglas usados no processo de implantação.

| Termo | Significado |
|-------|-------------|
| **SIGER®** | ERP da Rech Informática, objeto da implantação. Possui manual próprio via tecla **F1** em qualquer módulo. |
| **GRM** | Gestão por Resultados / repositório de processos (wiki) onde está descrito o processo de implantação. |
| **SICLA** | Sistema interno de CRM/registro de atividades da Rech (agendas, atendimentos, pendências, RNS). |
| **RNS** | Requisição registrada no SICLA. Pode gerar ou não "fichas". Tipos relevantes abaixo. |
| **RNS(I)** | RNS de **Implantação** — controla o projeto de implantação do cliente (status geral, datas, etapas por módulo). |
| **RNS ORC** | RNS de **Orçamento** — dimensiona horas/recurso (ex.: desenvolvimento, conversão) na etapa comercial. |
| **RNS COB** | RNS de **Cobrança/Execução** — derivada do ORC; é onde o trabalho é executado e as horas apontadas. |
| **Tipo 12** | Tipo de atividade no SICLA para **apoio comercial** (pré-implantação): agendas, atendimentos, pendências. |
| **Tipo 13** | Tipo de atividade no SICLA para **implantação** (pós-contrato). |
| **Tipo 84** | Agenda interna "Implantação/Treinamento Remoto" — gera atendimento que desconta horas da RNS(I). |
| **GCI** | Gerente/Coordenador da Implantação do cliente — em geral o consultor designado como gerente do projeto. |
| **GTI** | Setor responsável pela **instalação** do SIGER® (executa a RNS de instalação). |
| **Setor Adm** | Setor administrativo da implantação: prepara documentos, abre RNS por template, assinatura digital, arquivamento, links. |
| **Coordenação da Implantação** | Coordena o setor: recebe demandas do Comercial, designa consultores, controla RNS(I), conduz a transição. |
| **Gerente do Projeto** | Responsável por datas de uso oficial/encerramento, negociações em aberto e comunicação de encerramento. |
| **Equipe de Conversão** | Trata as RNS de conversão redigidas (backlog), layouts, prévia e conversão oficial dos dados. |
| **Suporte** | Canal de atendimento pós-implantação (telefone, e-mail, Teams). Recebe o cliente após a transição. |
| **Manutenção** | Setor que recebe demandas de natureza diferente do suporte. |
| **Sigla (da empresa)** | Identificador de 3 caracteres (letras/números, ex.: `A01`) atribuído a cada CNPJ na criação da empresa. |
| **Levantamento / Mapeamento** | Documento que mapeia os processos do cliente e a aderência ao SIGER®. |
| **Aderência ao SIGER** | Etapa de sincronizar o mapeamento com o uso efetivo das funcionalidades do SIGER®. |
| **Virada oficial** | Início do uso oficial (produção) do SIGER® pelo cliente. |
| **Ponto de corte** | Marco para conversão final de dados e/ou limpeza de movimentos de teste antes da virada. |
| **Termo de Encerramento** | Documento que oficializa o fim da implantação e a transição para o suporte. |
| **Follow up da RNS(I)** | Aba da RNS de Implantação onde se preenche o checklist de encerramento (itens a–i). |
| **1.1.P** | Menu de **parametrizações gerais** do sistema (genéricas). |
| **1.2.A** | Menu de **parametrizações por empresa**. |
| **1.2.M** | Menu de **compartilhamento de cadastros** entre empresas. |

## Pares ORC → COB mais comuns (conversões)

- Cadastros de Clientes/Fornecedores
- Cadastros de Produtos
- Movimentos do Financeiro a Pagar e Receber (documentos em aberto)
- Notas Fiscais já emitidas

Para cada item há uma **RNS ORC** (dimensionamento) e uma **RNS COB** (execução).
