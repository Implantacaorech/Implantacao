# Template de handoff de sessão

Copie este modelo ao encerrar uma sessão longa ou incompleta. Salve o handoff preenchido em
`memoria_ia/handoffs/AAAA-MM-DD-objetivo.md`. Mantenha **curto e objetivo**.

---

## Handoff — AAAA-MM-DD — <objetivo curto>

**Objetivo atual:** <o que se está tentando fazer, em 1 frase>

**Estado do projeto:** <o que já funciona / o que mudou nesta sessão; branch e último commit>

**Arquivos alterados:**
- `<caminho>` — <o que mudou>
- `<caminho>` — <o que mudou>

**Decisões tomadas:**
- <decisão> — <motivo>

**Pendências (o que falta):**
- [ ] <pendência> (P0/P1/P2)

**Comandos já executados:**
- `<comando>` — <resultado resumido>

**Próximos passos recomendados:**
1. <passo>
2. <passo>

**Riscos / atenções:**
- <risco, armadilha, decisão que exige aprovação humana>
